# German B1 grammar sources and editorial policy

## Official exam-skill context

The curriculum uses the current official Goethe-Zertifikat B1 description only to understand the communication skills and exam-module context:

- [Goethe-Zertifikat B1 — official exam page](https://www.goethe.de/ins/de/en/prf/gzb1.cfm)
- [Goethe-Institut examinations overview](https://www.goethe.de/en/spr/prf.html)

The official B1 page describes four modules—Listening, Reading, Writing, and Speaking—and B1 communication capacities such as understanding main information in clear standard language, understanding straightforward factual texts, producing connected language, and giving opinions, reasons, and explanations. It does **not** define a fixed public sequence of 24 grammar lessons.

## Editorial boundary

This app therefore uses the precise wording:

> German B1 grammar curriculum aligned with CEFR B1 communication needs and Goethe-Zertifikat B1 exam preparation.

It must not be called an “official Goethe grammar syllabus,” “official placement test,” or CEFR certification. Goethe branding, logos, question text, answer keys, and proprietary task content are not used.

## Content provenance

- All explanations, examples, mistakes, exercise prompts, distractors, and translations are original app-authored content.
- Each lesson is marked `sourceType: "original-curated"`.
- Existing original German B1 vocabulary is reused where it produces natural sentences.
- Official material informs skill alignment only; no question or textbook content is copied.
- German TTS receives the German example text with the course locale `de-DE`.

## Skill mapping method

Lesson `examSkills` tags indicate where a structure is likely to support communication:

- **Reading:** recognizing clause boundaries, case signals, reference, and text cohesion.
- **Listening:** following tense, connectors, modal meaning, and common spoken structures.
- **Writing:** producing connected, accurate messages and organized arguments.
- **Speaking:** explaining plans, opinions, reasons, wishes, and hypothetical situations.

Tags are recommendation metadata for later exam-prep integration. They do not claim that a grammar lesson mirrors a specific Goethe task or predicts a module score.
