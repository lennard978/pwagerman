# German B1 source boundary

Last verified: 2026-10-31

This project is an independent preparation tool by Asenda Studio. It is not affiliated with or endorsed by the Goethe-Institut. The name Goethe-Zertifikat B1 is used only to identify the public exam format that the preparation architecture references.

## Official structure and reference material

- [Current Goethe-Zertifikat B1 exam page](https://www.goethe.de/ins/de/de/prf/gzb1.cfm) — module names and current published durations.
- [Current Goethe-Institut examination regulations](https://www.goethe.de/pro/relaunch/prf/de/Pruefungsordnung.pdf) — general exam rules; the linked version reported a last-updated date of 1 September 2025 when verified.
- [Current B1 terms and conditions for exam administration](https://www.goethe.de/pro/relaunch/prf/de/Durchfuehrungsbestimmungen_B1.pdf) — B1-specific administration, structure, and scoring reference.
- [Official B1 preparation materials](https://www.goethe.de/ins/de/de/prf/gzb1/ueb.html) — official model and practice-set landing page.
- [Official accessible interactive B1 model test](https://bfu.goethe.de/b1_mod/index.php) — interactive model-test reference.
- [Official Goethe-Zertifikat B1 Wortliste](https://www.goethe.de/pro/relaunch/prf/de/Goethe-Zertifikat_B1_Wortliste.pdf) — lexical-scope reference.
- [Official module result information](https://www.goethe.de/de/spr/prf/pes.html) — each module is scored independently to a maximum of 100 points and passes at 60 points.

Official materials are references for structure, timing, task families, scope, and scoring only. They are not copied into the product.

## Original app-authored content

Vocabulary examples, explanations, exercises, distractors, prompts, recordings, and mock forms in this application are newly authored for this product. The Goethe sources are used only to check public structure, timing, task families, and lexical coverage. Development-only Listening fixtures are excluded from the production build.

Do not reproduce full official exam papers, answer keys, audio, logos, or Goethe visual identity. Future content reviews should record provenance, author, licence/status, review date, and the official structural reference used.

## Release configuration decisions

- Reading: 65 minutes, 5 parts; objective score, maximum 100, module pass threshold 60.
- Listening: 40 minutes, 4 parts; objective score, maximum 100, module pass threshold 60.
- Writing: 60 minutes, 3 parts; module-specific assessment.
- Speaking: about 15 minutes as a pair module, 15 minutes preparation, 3 parts; module-specific assessment.
- There is no application-defined aggregate average or overall pass/fail rule.

Before shipping later exam-content phases, re-check all links and the current regulations because official formats and documents can change.
